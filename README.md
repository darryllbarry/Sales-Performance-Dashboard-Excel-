# Superstore Sales Performance Dashboard (Excel)

Interactive dashboard built from the Superstore dataset (9,994 rows, 2014-2017).

**Tools:** Excel Tables, PivotTables, PivotCharts, slicers, GETPIVOTDATA

**Key findings**
- $2.3M sales, $286K profit, 12.5% margin, 5,009 orders
- West is the most profitable region; Central has the lowest margin (7.9%)
- Tables, Bookcases and Supplies lose money, with heavy discounting the likely cause
- Sales peak every November and grew each year from 2015 to 2017
